Ответы на вопросы по адаптивной вёрстке

1. Что такое Viewport meta tag и почему он важен?

Мета-тег <meta name="viewport" content="width=device-width, initial-scale=1.0"> сообщает браузеру, что ширина страницы равна ширине экрана устройства, а масштаб — 1:1. Без него мобильные браузеры показывают страницу в десктопной ширине и уменьшают её, делая текст нечитаемым. Тег обязателен для адаптивной вёрстки.

2. Какие подходы использовались?

Responsive (отзывчивый) и Fluid (резиновый). Responsive — через медиа-запросы на разных брейкпоинтах. Fluid — через относительные единицы (%, rem, vw, clamp), чтобы элементы плавно менялись без резких переходов. Оба подхода применены: сетки через Grid/Flexbox + медиа-запросы и clamp() для типографики.

3. Как работает Mobile First и в чём преимущества?

Mobile First — сначала стили пишутся для мобильных, потом через min-width добавляются правила для больших экранов. Преимущества: легче оптимизировать производительность (мобильные устройства слабее), меньше лишнего CSS, лучше для SEO. Desktop First — наоборот: сначала десктоп, потом через max-width сужаем.

4. Какие единицы предпочтительны?

%, rem, em, vw, vh. % — для ширины контейнеров. rem — для шрифтов и отступов (зависит от корневого размера). em — для шрифтов внутри компонента. vw/vh — для пропорциональных размеров (например, hero на всю высоту экрана). Абсолютные px применяются только для мелких деталей.

5. Как работает clamp()?

clamp(min, preferred, max) задаёт значение с тремя границами. Браузер выбирает среднее, ограничивая его минимумом и максимумом. Пример: font-size: clamp(1.5rem, 5vw, 2.5rem) — шрифт плавно растёт от 1.5rem до 2.5rem в зависимости от ширины окна. Удобно для адаптивной типографики без медиа-запросов.

6. Какие брейкпоинты использовались?

1024px — планшет, 768px — мобильные, 480px — маленькие мобильные. Значения выбраны по типичным размерам популярных устройств: iPad (768–1024), смартфоны (480–768), узкие смартфоны (<480).

7. Как медиа-запросы помогают?

@media (max-width: 768px) { ... } применяет стили только при выполнении условия. Пример: @media (max-width: 768px) { .nav-toggle { display: block; } } — кнопка меню появляется только на мобильных. Медиа-запросы позволяют полностью перестроить макет для разных экранов.

8. Разница между max-width и min-width?

max-width — стили применяются, пока ширина не превышает значение. Подходит для Desktop First: сначала десктоп, потом сужаем. min-width — стили применяются от значения и выше. Подходит для Mobile First: сначала мобильные, потом расширяем. Синтаксис: @media (max-width: 768px) против @media (min-width: 769px).

9. Как сделать изображения адаптивными?

Основные свойства: max-width: 100% и height: auto. Картинка не выходит за пределы контейнера, сохраняет пропорции. Дополнительно — display: block убирает лишний отступ под изображением. Для разных разрешений используют srcset и <picture>.

10. Какие инструменты браузера помогают тестировать?

DevTools (F12). Режим адаптивного дизайна (Ctrl+Shift+M в Chrome/Edge) — переключение разрешений, эмуляция устройств (iPhone, iPad, Android). Вкладка Layout — просмотр Flexbox и Grid. Вкладка Elements — анализ применённых CSS-правил. Lighthouse — проверка производительности и доступности.
