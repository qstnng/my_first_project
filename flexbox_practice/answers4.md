Ответы на вопросы по Flexbox

1. Какое основное свойство CSS включает Flexbox и что происходит с дочерними элементами после его применения?

Основное свойство — display: flex (или display: inline-flex). После его применения контейнер становится flex-контейнером, а все его прямые дочерние элементы — flex-элементами. Они автоматически выстраиваются в ряд по основной оси (по умолчанию flex-direction: row), получают возможность растягиваться и сжиматься в зависимости от доступного пространства, подчиняются правилам выравнивания по основной и поперечной оси.

2. В чем разница между justify-content и align-items?

justify-content управляет распределением элементов вдоль основной оси (main axis). При flex-direction: row это горизонталь. align-items управляет выравниванием элементов вдоль поперечной оси (cross axis). При flex-direction: row это вертикаль. Пример: justify-content: center центрирует карточки по горизонтали, align-items: stretch растягивает их по высоте контейнера.

3. Что делает свойство flex-direction и какие значения может принимать?

flex-direction задаёт направление основной оси, вдоль которой выстраиваются элементы. Значения: row (по умолчанию, слева направо), row-reverse (справа налево), column (сверху вниз), column-reverse (снизу вверх). От значения зависит, как интерпретируются justify-content и align-items.

4. Объясните значение трех свойств в сокращенной записи flex: 1.

flex: 1 — это сокращение для flex-grow: 1, flex-shrink: 1, flex-basis: 0%. flex-grow разрешает элементу растягиваться при наличии свободного места, flex-shrink позволяет сжиматься при недостатке, flex-basis задаёт начальный размер элемента перед распределением пространства.

5. Как работает свойство flex-wrap и в каких случаях его следует использовать?

flex-wrap определяет, переносятся ли элементы на новую строку, если не помещаются в одну. Значения: nowrap (по умолчанию), wrap, wrap-reverse. Используется, когда элементов много и нужно сохранить их размеры без сжатия — например, карточки в галерее, теги, галерея миниатюр.

6. Чем отличается align-content от align-items и когда применяется каждое из этих свойств?

align-items выравнивает элементы внутри одной строки по поперечной оси. align-content выравнивает сами строки, когда их несколько (при flex-wrap: wrap). Если строка одна, align-content не действует. align-items работает всегда, align-content — только при многострочном контейнере.

7. Как свойство order влияет на отображение элементов и в каких практических ситуациях оно может быть полезно?

order задаёт порядок отображения элементов независимо от их места в HTML-разметке. Применяется, когда нужно визуально переставить блоки без изменения структуры документа — например, вывести главную карточку первой на мобильных устройствах, а на десктопе — по центру. По умолчанию order: 0.

8. Что такое «осевая линия» (main axis) и поперечная ось (cross axis) в Flexbox и как они связаны с flex-direction?

Основная ось (main axis) — направление, заданное flex-direction. Вдоль неё выстраиваются элементы и работает justify-content. Поперечная ось (cross axis) — перпендикулярна основной, вдоль неё действует align-items. При flex-direction: row основная ось горизонтальная, поперечная вертикальная. При flex-direction: column — наоборот.

9. Как создать адаптивный макет с помощью Flexbox без медиа-запросов?

Использовать flex-wrap: wrap вместе с flex-basis и min-width. Пример: .card { flex: 1 1 220px; } — карточки занимают равную ширину, но при нехватке места переносятся на новую строку. Контейнер .content { display: flex; flex-wrap: wrap; gap: 20px; } автоматически перестраивается под ширину экрана. Это работает без медиа-запросов.

10. Какие преимущества дает использование gap вместо margins для создания промежутков между flex-элементами?

gap задаёт промежутки между элементами без добавления отступов по краям контейнера. Не нужно компенсировать margin у первого и последнего элемента. Работает одновременно по строкам и колонкам. Код чище, не появляется двойных отступов, значение меняется в одном месте. Поддерживается во всех современных браузерах.
