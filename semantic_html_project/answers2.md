# Ответы на вопросы по семантической верстке

1. Чем семантическая верстка отличается от несемантической и почему она важна?

Семантическая верстка использует теги по смыслу (header, nav, article), несемантическая — универсальные div и span. Семантическая важна для доступности (скринридеры), SEO (поисковики понимают структуру) и читаемости кода.

2. В каких случаях следует использовать article вместо section?

article — для самостоятельного законченного блока (статья, пост), section — для тематической группы внутри чего-то. В работе article применён для «Укиё-э», «Икебана», «Оригами», section — для подразделов статьи («Кацусика Хокусай», «Хиросигэ и дорога Токайдо»).

3. Для чего предназначены header и footer и могут ли использоваться несколько раз?

header — вводная часть страницы или раздела (заголовок, навигация). footer — завершающая часть (автор, контакты, копирайт). Могут использоваться несколько раз: один header для страницы, другие — внутри article.

4. Какой тег для основного контента и почему не div?

main. div не несёт семантики, поисковики и скринридеры не понимают, что это главная часть. main явно указывает на основной контент.

5. В чем разница между nav и обычным списком ссылок?

nav — семантический тег для навигации. Список ссылок — просто ul со ссылками. nav обязателен для основной навигации по сайту (меню, хлебные крошки, оглавление).

6. Для чего атрибут datetime в теге time?

datetime задаёт машиночитаемый формат даты (2026-03-12), понятный поисковикам и браузерам. Важен для SEO, микроразметки, корректного отображения в разных локалях.

7. Преимущества figure и figcaption?

Семантически связывают изображение и подпись. Скринридеры понимают, что подпись относится к этому изображению. Простой img с p такой связи не даёт.

8. Когда использовать aside?

Для контента, косвенно связанного с основным: боковые панели, реклама, ссылки на похожие статьи. В работе в aside помещён список популярных направлений.

9. Как семантика влияет на SEO и доступность?

Помогает поисковикам понять структуру и значимость контента (заголовки, статьи, навигация). Для доступности — скринридеры корректно озвучивают страницу, пользователи с ограничениями быстрее перемещаются по разделам.

10. Какие теги использованы для структуры?

header, nav, main, article, section, aside, footer, figure, figcaption, time, details, summary, address, table, form. Они формируют логичную структуру, помогают поисковикам и пользователям.
