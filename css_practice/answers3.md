# Ответы на вопросы по CSS: селекторы, каскад, наследование

1. В чем разница между селектором по классу и по ID?

Селектор по классу (.class) имеет специфичность 0,1,0 и может применяться к нескольким элементам. Селектор по ID (#id) имеет специфичность 1,0,0 и должен быть уникальным на странице. Класс используется многократно, ID — один раз.

2. Как работает каскад в CSS?

Каскад определяет порядок применения стилей при конфликте. Приоритет: 1) важность (!important), 2) специфичность селектора, 3) порядок объявления (позже — приоритетнее). При равной специфичности применяется правило, объявленное ниже в файле.

3. Рассчитать специфичность для селекторов:

ul li.important — 0,1,2 (один класс, два тега)
#site-title — 1,0,0 (один ID)
.content > .featured-post — 0,2,0 (два класса)

4. Какие свойства наследуются по умолчанию, а какие нет?

Наследуются: color, font-family, font-size, line-height, text-align.
Не наследуются: margin, padding, border, background, width, height.

5. Как работает селектор > и чем отличается от селектора потомков?

Селектор > выбирает только прямых детей. Селектор через пробел — всех потомков на любой глубине. Например, .content > article выберет только прямые article внутри .content, а .content article — все вложенные.

6. Для чего используются :hover и :nth-child()?

:hover — стиль при наведении курсора (кнопки, ссылки, карточки). :nth-child() — выбор элементов по порядку (чётные/нечётные строки таблицы, каждый третий элемент списка).

7. Что делает !important и почему его следует использовать с осторожностью?

!important переопределяет все обычные правила, включая более специфичные. Использовать осторожно, потому что он ломает естественный каскад, усложняет отладку и поддержку кода. Применять только в крайних случаях (например, переопределение стилей сторонних библиотек).

8. Как ::before и ::after расширяют возможности CSS?

Псевдоэлементы ::before и ::after добавляют контент до или после содержимого элемента без изменения HTML. Могут содержать текст, символы, изображения (через content), декоративные элементы. Часто используются для иконок, кавычек, маркеров.

9. В каком порядке браузер применяет CSS-правила при одинаковой специфичности?

При одинаковой специфичности применяется правило, объявленное позже в исходном коде (или в подключённом файле, который идёт позже). Если один стиль во внешнем файле, другой во встроенном <style> — встроенный ниже по каскаду, если объявлен позже. Инлайн-стили (style="") имеют более высокий приоритет.

10. Как инструменты разработчика помогают анализировать и отлаживать CSS?

DevTools показывают: применённые стили (Styles), перечёркнутые (переопределённые) правила, итоговые вычисленные значения (Computed), источник каждого правила (файл и строка). Позволяют менять значения в реальном времени, проверять специфичность, наследование, box-model.
