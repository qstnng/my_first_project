Ответы на вопросы по CSS Grid

1. Какое основное свойство включает CSS Grid и чем принципиально отличается от Flexbox?

Основное свойство — display: grid. Grid — двумерная система: работает одновременно со строками и столбцами. Flexbox — одномерная: элементы выстраиваются вдоль одной оси (строки или столбца). Grid удобен для макетов страниц, Flexbox — для выравнивания элементов внутри контейнера.

2. В чем разница между grid-template-columns и grid-auto-columns?

grid-template-columns задаёт явные столбцы сетки. grid-auto-columns определяет размер автоматически создаваемых столбцов для элементов, выходящих за пределы явной сетки. Первое — для планируемых колонок, второе — для динамически добавляемых.

3. Что делают функции repeat(), minmax() и auto-fit?

repeat() повторяет определение столбцов заданное число раз: repeat(3, 1fr). minmax() задаёт минимальный и максимальный размер: minmax(200px, 1fr). auto-fit автоматически подбирает число колонок под ширину контейнера. Пример: grid-template-columns: repeat(auto-fit, minmax(200px, 1fr)) — адаптивная сетка без медиа-запросов.

4. Как работают именованные grid-области?

Через grid-template-areas задаются строки с именами областей: "header header" / "nav main". Затем элементы получают grid-area: header, nav, main. Преимущество — макет читается визуально в CSS, легко переставлять блоки.

5. Объясните систему нумерации grid-линий и как размещать элементы.

Линии нумеруются от 1. grid-column: 1 / 3 — элемент занимает от первой до третьей линии (два столбца). grid-row: 2 / 4 — две строки. Можно использовать span: grid-column: span 2.

6. Что такое gap и чем он лучше margins?

gap задаёт промежутки между строками и столбцами сетки. Не нужно добавлять margin каждому элементу, не появляется двойных отступов, значение меняется в одном месте. Работает и по строкам, и по столбцам.

7. Как justify-items и align-items влияют на выравнивание?

justify-items выравнивает содержимое ячеек по горизонтали внутри своей области (start, center, end, stretch). align-items — по вертикали. Например, align-items: center центрирует элементы по вертикали в своих ячейках.

8. В чем разница между auto-fill и auto-fit?

auto-fill создаёт столько колонок, сколько помещается, даже если они пустые. auto-fit схлопывает пустые колонки, растягивая существующие элементы на всё пространство. При малом числе элементов auto-fit даёт более плотную сетку.

9. Как создать сложные макеты с помощью grid-template-areas?

Области задаются строками: "header header" / "nav main" / "footer footer". Все строки должны быть одинаковой ширины. Имена — латиница, без пробелов. Точка (.) означает пустую ячейку. Элементы получают grid-area с именем области.

10. Какие преимущества Grid перед другими методами?

Grid даёт двумерную раскладку в одном контейнере без вложенных блоков. Позволяет управлять строками и столбцами одновременно, легко создавать адаптивные сетки через auto-fit и minmax, читаемо описывать макет через grid-template-areas. Упрощает код по сравнению с float и таблицами.
